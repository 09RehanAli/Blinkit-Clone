# 🛒 Blinkit Clone

A static, responsive front-end clone of the **Blinkit** quick-commerce website, built using **HTML** and **CSS**. This project recreates the look and layout of Blinkit's home page, including the header, hero banner, category grid, product sections, and footer.

🔗 **Live Demo:** [https://09rehanali.github.io/Blinkit-Clone/](https://09rehanali.github.io/Blinkit-Clone/)

## ✨ Features

- **Navigation bar** with logo, "Delivery in 14 minutes" tagline, delivery location, Login and My Cart buttons
- **Hero banner** with a promotional image
- **Category section** with clickable-style category cards (Pharmacy, Pet Care, Baby Care, Paan Corner, and more)
- **Product sections** with product cards showing:
  - Product image
  - Delivery time badge (10 mins)
  - Product name and weight
  - Discounted price and original price
  - ADD button
- **Product categories** such as *Dairy, Bread & Eggs* and *Rolling Paper & Tobacco*
- **Detailed footer** with useful links, category lists, and app download badges (App Store / Play Store)
- Clean layout that closely follows the original Blinkit design

## 🚀 Getting Started

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/09rehanali/Blinkit-Clone.git
   ```

2. **Go to the project folder**
   ```bash
   cd Blinkit-Clone
   ```

3. **Open the website**
   Double-click `index.html`, or open it with a local server such as the VS Code **Live Server** extension.

---

## 🌐 Deployment

This site is hosted using **GitHub Pages**. To deploy your own copy:

1. Push the project to a GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and the `/ (root)` folder
4. Click **Save** — your site will be live in a minute or two
